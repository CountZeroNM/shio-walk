## 2026-11-19 に直したこと

- **他人のウォークを書き換えられた**: 更新・完了 API がウォークの持ち主を確かめていなかった → user_id も条件に
- **記録が消える**: ウォーク中に再読み込み・アプリが落ちたあとセンサーを動かすと、歩数を 0 から数え直し、次の自動保存でサーバーの値を上書きしていた → 「起点 + センサーの分」に
- **計測中に古い一覧で上書き**: 保存のたびの `load-walks` で手元の値が戻っていた → 計測中は手元の値を残す
- **新しい環境で DB ができない**: マイグレーションのファイル名が migratus の書式でなく、何も適用されていなかった (既存の DB は手で作られていた) → 書式を直し、既存の DB でも通るように
- **時刻**: タイムゾーン無しの文字列 (`2025-12-18 10:00:00.0`) を返していた → TIMESTAMPTZ・ISO-8601 の UTC
- **単位の推測**: `distance` が 100 未満なら km とみなしていた → `distance-meters` だけ
- **完了**: 「保存 → 完了」の 2 回の通信を、最終値つきの 1 回 (1 トランザクション) に
- **ドキュメントにあって実装に無かった**: 画面が隠れる/戻るときの保存 (visibilitychange) → 実装
- **IP の直書き**: `api.cljs` の URL を環境ごとに書き換えていた → 同じ Origin の `/api` (開発サーバーが転送)
- **更新が届かない**: Service Worker がキャッシュ優先で、新しい main.js がスマホに届かなかった → ネットワーク優先
- テストを追加: API (51 件の検査) と画面のイベント (9 件)

## 既知の問題・制約

- **画面ロック・バックグラウンドではセンサーも GPS も止まる** (iPhone Safari・Android Chrome とも。ブラウザの制約)。止まっている間の歩数は数えられない
- 加速度からの歩数の判定 (しきい値 1.3、間隔 280 ms) は簡易なもので、精度は端末と持ち方しだい
- GPS は精度 30 m 未満の点だけを使い、点と点の直線距離を足す。止まっていても揺れで少し増えることがある
- re-frame のイベントハンドラの中で API 呼び出し・localStorage・タイマーを直接行っている (副作用を effect に分けていない)。`http-fx` は依存にあるが未使用
- 報酬の画像・音声 (`image-url` / `audio-url`) はまだ無い
- LAN 用の自己署名証明書の秘密鍵が一時コミットされていた (2026-03-08)。2026-11-19 に全ブランチの履歴から消して強制 push した。GitHub には古いコミットの ID を直接指せば見える形で残るので、その証明書は使わないこと (作り直す)
